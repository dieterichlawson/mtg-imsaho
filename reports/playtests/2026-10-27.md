## D58: every input a resume or a replay assumes

**Method.**
- A stub hashed `--system-prompt` and stdin into the pick, so any drift
  changed the pick. It hung after 30 picks to leave a snapshot to
  resume.
- Each input was changed alone, on three surfaces: a batch `--resume`,
  `mtg-draft-server --resume` and `mtg-draft-replay`.

**Controls.** With nothing changed, the resumes and the replay matched
the reference run exactly: 48/48 calls on each resume and 10/10 on the
replay.

**Results:**

| Input | Batch resume | Hosted resume | Positions replay |
|---|---|---|---|
| guide added, dropped or edited | warned (wording #950) | **silent** (#948) | recorded |
| `MTG_LLM_HISTORY` | **silent** (#949) | **silent** (#949) | recorded |
| `MTG_CLAUDE_CODE_DRAFT_ANSWERS` | **silent** (#949) | **silent** (#949) | recorded |
| `MTG_LLM_THINKING` | silent (#949) | not tried | silent (#949) |
| seat model | warned | the snapshot wins, no note (#952) | n/a |
| `--seed/--players/--best-of` | noted, the save wins | the save wins, no note (#952) | n/a |
| card pool | refused (#924 holds) | refused | **silent** (#951) |
| set file's `set_name` | silent | silent | silent (#951) |

A repeated flag (`--seed 1 --seed 2`) is read from its first occurrence
by the runner and the replay tool, and from its last by the server
(#952).

## H30: a this-turn ledger

**Method.**
- Every this-turn and last-turn condition in the pool was read against
  `GameView` and the three surfaces.
- A ledger script over about 165 stub games' PROMPT blocks reported each
  event that no later prompt of the same turn restated. A checker
  recomputed the `This turn:` line from the events.

**Checked, correct:**
- `This turn:` agreed with the events in all 7,452 prompts. Flashback
  casts are counted, a token's death sets morbid, and both reset at the
  turn.
- #932's `damaged_by` reached the prompt row, the CLI inspector and the
  page's hover.
- The werewolf upkeep trigger is on the stack with the right condition.

**Gaps.** These facts are on no surface after one prompt:
- Moonmist's prevention for the turn (#953).
- Whether a creature attacked this turn, which Homicidal Brute's
  end-step trigger depends on (#954).
- Darkthicket Wolf's once-each-turn ability (#954).

**Found on the side:**
- The page's inspector prints keywords as `FirstStrike` (#955).
- `--check-invariants` changes a `cc` game (#956).
