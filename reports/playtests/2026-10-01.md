## V47 — the two game loops as one protocol (code read)

Put `mtg-runner/src/main.rs`'s callback beside `mtg-draft-runner`'s
`play_game`. One real divergence, of exactly the shape the idea predicts:
`mtg-runner` answers the 50,000-action ceiling with `Action::AbandonGame`
(#233 — "a loss nobody chose"), while the draft loop sends
`watchdog::forfeit_move()`, which is `Concede`, for whichever seat happens to
be acting. #559 fixed the *mechanism* of that branch and put the ceiling and
the stall forfeit on one move. `stalled_seat` stays `None`, so the standings
count it as an ordinary win and no WARN or draft-log line is written (#630).
Reachability is low (a 40-card game decks out long before 50,000 decisions
outside a flood), which the issue says.

Checked, correct: the draft seat's card reference is the whole set's names,
not the opponent's decklist, so #466's leak does not apply there; the stall
arm forfeits the stuck seat and reports it everywhere; the draft loop has no
`--check-invariants`, `--save` or streamed log by design (no flag for them).

## V51 — the answer the program changed

**Every CLI value prompt refuses out loud or honours; none substitutes.**
Damage-assignment order (`1` → "missing 0", `1 0 1` → "1 is listed twice",
`01 00` honoured), set screens (toggle, "3 marked — mark at most 2", ranges
refused), blockers (illegal pair, double use, menace minimum all refused), X
(`3.0`, `-0`, `6`, `1e1` refused, `+3` honoured and logged `X=3`), and the
engine re-validates every set answer. #595 still holds.

The substitution lives in the seat that never sees a refusal: the LLM
attackers schema has `minimum: 0` and no `maximum`/`enum`, and the parser
filters out-of-range indices silently. A stub answering out of range on 32
attack prompts got 0 attacks and 0 rejections counted; a creature sent only
at `planeswalker 1` with one walker attacks nowhere (#635). Also found: the
Liliana pile chooser numbers piles 0/1 in the heading and "Pile 1/2" in rows
and log, so typing `1` for Pile 1 sacrifices Pile 2 (#636); combat damage
amounts are never asked — exactly lethal per blocker, trample the rest
(CR 510.1c-d, deferred by #65 and never tracked; #637); Feeling of Dread and
Avacynian Priest tap without a log line (#638); Harvest Pyre's exile cost is
logged as a bare count (#639).

Checked, correct: a blocker removed before damage sends all of the
attacker's damage to the survivor (CR 510.1c); the random seat rolls every
set size; `pick_action_index` logs its fallback.

## V50 — the budget on the other three surfaces

Flood mirror, seed 7, pruned to 100–2,000 permanents. **#565's fix holds**:
random-vs-random at 1,000 permanents is 47 ms/decision (#565 had 15–23 s per
keypress), the `--check-invariants` multiplier is down to 1.2–2.2x, RSS peaks
at 94 MB at 5k permanents, and no frame on the wire exceeds 1.9 MB.

The walls moved elsewhere:

| permanents | random ms/decision | declare-blockers gap | page render | LLM blockers schema |
|---|---|---|---|---|
| 250 | 5.9 | 0.08 s | 101 ms | 0.03 MB |
| 500 | 17 | 0.47 s | 390 ms | 0.11 MB |
| 1,000 | 47 | 3.4 s | 1,929 ms | 0.48 MB |
| 2,000 | 151 | 26.9 s | 21,220 ms | 1.99 MB |

- The page's `clip()` trims one character per `measureText`, O(L²), on a
  declaration line that names every creature — 17,000 characters at 2,000
  permanents. Confirm → next screen took 110 s at 1,000 (#640).
- Legal blocks are built per (blocker, attacker) pair, each walking the
  board: cubic (#641).
- The LLM blockers schema is an enum of attackers per blocker: a×b (#642;
  size from the code, API outcome unverified).
- The page has no "attack with all" (#643); `fuzz.sh` has no per-game
  timeout, latent because no coverage pair builds a flood (#644).

The nightly fuzz job is not paying any of this: 300 coverage games, slowest
1.58 s.
