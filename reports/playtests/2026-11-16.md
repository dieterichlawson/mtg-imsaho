# Playtest 2026-11-16: the CLI

R2 found no new code and no fresh untried idea, so the rotation chose the subject. The CLI had gone longest without a night: V 11-11 and M 10-28, against C/L 11-12, H 11-13, G 11-14 and D 11-15. Every V and M id has been run before, so the night took the four that had gone longest unrun, each as an abuse probe at every prompt type it could reach:

- **V8**, search and pane abuse (a subagent, tmux);
- **V9**, concede and new-game churn (the same subagent);
- **V12**, control characters and escape sequences (a subagent);
- **V14**, save and resume corruption (a subagent).

All four ran in parallel, each on its own tmux socket. The night filed **#1046-#1059**:

- **Four are `sev:game-affecting`:**
  - #1046, a ghost stack source;
  - #1047, a missing save key loading as its default, which flipped a game's winner;
  - #1051, Ctrl-R taken as the hot-reload chord;
  - #1053, the hot-reload snapshot deleted by the next launch.
- **The other ten are `sev:presentation`.**

Nothing was wrong with the rules. No `cc` seat and no metered seat was spawned; the only LLM traffic was V14's draft snapshots under the prompt stub.

## R1: propagation sweep (issues closed 2026-11-15)

All of it was done as code reads. Every fix held on the surfaces it did not name:

- **#1032 (exact tiebreakers).** There is one sort, in `mtg-draft/src/tournament.rs`. `standings.rs`, the draft page's `tiebreakText` and the client's row print its floats only. The draft loop's `ledger.py` reads the rank the runner printed. `report.py` falls back to points and game wins only for nights recorded before ranks existed.
- **#1034, #1035, #1038 (a closed table on the pages).** The terminal client prints `the table is closed: <reason>` and returns, with no view left to draw stale. The host's `cli` seat is the same code.
- **#1036 (one kick, one reason).** `away_reason` now names the seat. `kicked` and the name are in `TableSave`, so a resumed table gives later forfeits the same words.
- **#1045 (`q`/`exit` at the host).** `SEAT_COMMANDS`, the seat help at the host's terminal, names no leave word, and the host's help names only `quit`. The client's own `quit | q | exit` still means leave.
- **#1040, #1042, #1043, #1044.** Each is single-surface: the client and the host's `cli` seat share `client.rs`, and the kick is refused in the lobby, which both the page and the terminal read.

## V12: control characters and escape sequences

There were 8 sessions: seeds 1201-1204 and 1208, two staged boards, and one at 80x24. Every prompt type was reached except trigger ordering.

**Checked, correct:**
- About 45 keys and chords, sent at every prompt, typed nothing and opened no pane.
- An unbound key splits a number rather than joining it, and the result is refused out loud: `0 C-l 1` gives `'0 1'`, and `2 C-] 3` at X gives `Invalid input '2 3'`.
- Ctrl-L, Ctrl-F and Ctrl-D are not the `l`, `f` and `d` shortcuts.
- A typed CSI is swallowed whole.
- At the concede confirmation, Esc declines.
- At 80 columns, `/` refuses with "needs at least 100 columns".

**Found:**
- **#1051.** The second key of the `rr` chord is checked without its modifiers, so `r` followed by Ctrl-R or Alt-r ends the game and runs `cargo build --release`.
- **#1053.** When the build fails, the program prints "Resume manually with … --resume /tmp/mtg-hot-reload-<pid>.json". The next `mtg-runner` launch of any kind deletes that file as a dead run's (`sweep_stale_hot_reload_saves`). This was split out of #1051.
- **#1052.** A bracketed paste of `\e[2J` into the `/` search or the library-search filter is printed raw, so the terminal clears the frame. The same paste at a menu prompt is shown as `·[2J` and refused.

## V14: save and resume corruption

There were 104 attempts: 75 corrupt game saves and 29 corrupt draft snapshots. The draft snapshots were run under the stub `claude`.

**Checked, correct:** every unreadable file, wrong-shaped file, out-of-range value, bad player or object index, fake card name, wrong-id object, self-attachment and bad draft snapshot is a clean error with exit 1. Nothing panicked or hung. A save with negative life loads and is ended at once by SBA (CR 704.5a).

**Found:**
- **#1046.** A stack `Ability` whose `source_id` was never allocated resolves as `? (#99999) dealt 2 damage to p1`, with exit 0 under `--check-invariants`. A `Spell(99999)` is refused.
- **#1047.** serde ignores unknown keys and defaults missing ones. A missing or misspelled `base_controller` makes every permanent p0's, and a stolen creature never returns, which flipped the winner of a staged Traitorous Blood game. 5 of 8 random bit flips landed in key names and loaded silently.
- **#1048.** A draft snapshot with fewer `seats` entries than players is accepted, and the missing seat's guide or model change is not announced.
- **#1049.** `--resume` drops `--on-the-play` with no note, where `--deck1`, `--deck2` and `--seed` each get one.
- **#1050.** The unknown-seat error lists every seat type but `gui`.

**Accepted, and checked harmless:** `graveyard_order` naming a library card, a missing id or a duplicate (it is only a sort key), and a dangling target list on a Mountain.

## V8: search and pane abuse

There were 3 games, two of them staged, at 80x24 and 100x24.

**Checked, correct:**
- No pane key took an action or ate an answer. `l C-m C-m 1 C-m` at the mulligan opened the log and kept the hand.
- Marks survive panes and paging.
- Every pager reaches its last entry at 80x24.
- No row crossed a border.
- Esc and q are documented as unbound, and Enter returns.

**Found:**
- **#1054.** The X-funding prompt refuses every pane key as "enter an integer between 0 and 7".
- **#1055.** The deck browser `d` counts 39 cards for a 40-card deck with a spell on the stack.
- **#1056.** The CARDS pane and the `/` results stop after a few matches with no count, no "N more" and no pager, and a search with no match shows an empty pane with no message.
- **#1058.** The log, graveyard and exile pager and the card detail pages ignore `n` on the last page in silence, where the deck browser says "Already at the last page."
- **#1059.** `/` opens search on the keypress at the menu but only after Enter at the target chooser.

## V9: concede and new-game churn

There were 20 games and 28 launches, counting 8 resumes.

**Checked, correct:**
- No stale board, log, hand or notice appeared in any new game's first frame.
- Each log has one GAME_START, and a RESULT only for a finished game.
- RESUMED lines append to the log.
- Type-ahead before launch is dropped.
- No hot-reload file was left in /tmp.
- Exit codes: concede 0, Ctrl-C 130, SIGTERM 143, and `--resume` of a finished save 1 with a clean error.

**Found:**
- **#1057.** Ctrl-C and SIGTERM print nothing to the terminal or the `--log`, so the log stops mid-game. This is #823's shape, fixed for `mtg-draft-server` and not for `mtg-runner`.

## What the night taught

Two findings came from reading the program against itself rather than against the rules:

- **#1058, #1059:** two viewers, or two screens of one cast, that answer the same key differently.
- **#1047:** serde's defaults standing in for validation.

Each is a shape worth sweeping on purpose. Both have been added to `cli.md`.
