## H37: what an AI seat is asked between games (first run)

`mtg-draft-runner --model cc --players 2 --best-of 3 --seed 37` ran under `scripts/llm-prompt-stub.py`, three times. The match went 2-0 for seat 0, so there were two between-games calls per run.

- **Cache TTL.** A wrapper recorded the env of each call. Both between-games calls had `MTG_CLAUDE_CODE_CACHE_TTL=1h` with `FORCE_PROMPT_CACHING_5M` unset. All 78 picks, 2 builds and 314 game calls had `FORCE_PROMPT_CACHING_5M=1`. Holds.
- **Schema.** Both seats, with two different pools, were sent one sideboard schema (sha `2685b20a9ab7a804`). Its keys are `maindeck` (an index array), `lands` (the five basics), `play_first` and `thoughts`. No card name is a key. Holds.
- **Hidden information.** The prompt listed the opponent's 21 shown cards. `game.rs` `shown_cards` takes them from the battlefield, graveyard, exile and stack only, tokens excluded. Nothing from hand or library can reach it. Holds.
- **Who chooses.** Only the loser of game 1 is told it chooses, and only its line carries a choice.
- **A bad answer.** The second run's wrapper answered with a 0-card deck and no `play_first`. Both seats kept their decks, and the log says why: "kept the deck (the answer's could not be played: Maindeck is empty …)". But the choosing seat's line ends "| plays first", as though it had chosen. `log_between` says "(no choice was made)" for the same case. Filed **#1023**.
- **Answers in text.** The third run set `MTG_CLAUDE_CODE_DRAFT_ANSWERS=text`. The format line names `maindeck`, `lands` with the five basics, and `play_first`, which are the fields the reader uses. The answer is re-serialised as JSON before `play_first` is read, so text answers keep the choice.
- **The game seat's match paragraph.** While reading the game seats' SYSTEM records I found game 1 saying "Neither of you can win the match with this game; 2 more games follow it." The match ended 2-0 in game 2. `left` is the most games that can follow, not the number that will. Filed **#1022**.

## H38: every re-ask has a cause (re-run, the first night with reasons)

`reports/draft-loop/nights/2026-11-13.md` lists 6 re-asks in 2,764 game calls:

- **3 × `then[i]` names a card not in hand.** The cards were Rotting Fensnake (Ghoulraiser returns a random Zombie, so the seat planned a card it did not yet hold), Silent Departure and Think Twice. The last two were in the graveyard, so the seat meant flashback. `PLAN_DESCRIPTION` says "cards from your hand, by name alone", so these are model slips, not invited answers. The format line gives `"then": [string]` without the allowed names; that is H38's old hypothesis. It did not matter here, because the slip was about zone, not spelling. Not filed.
- **3 × `action` is missing over `{"ask_again":true,"attack":[],"then":[]}`.** The seat made no play and asked to be asked again. The format line lists `action` first after `thoughts` on every priority question (checked across a stub game's 52 FORMAT lines). Why the seat answered this way would be in its `thoughts`. A stub game (`mtg-runner --p1 cc --p2 random --seed 38`, a wrapper dropping `action`) shows where the reasoning goes: it is logged as the `THOUGHT` line immediately before the `REASK`, and `ledger.py` keeps only the `REASK`. Filed **#1024**. Whether `ASK_AGAIN_DESCRIPTION` invites this cannot be known until the record keeps the thought.
