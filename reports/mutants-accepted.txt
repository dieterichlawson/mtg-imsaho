# The 2026-09-08 re-run of issues #276-#279 (see reports/mutation-testing.md,
# "The invariant checker's own clauses, re-run and triaged"). Each of these
# was read against the two questions in docs/mutation-testing-guide.md and
# kept only where the mutated clause cannot behave differently on any state
# this card pool can reach.
#
#   events.rs `+ with *`: the index arithmetic is `events[i * 1 ..]`, which
#     is `events[i ..]`. The mutation re-includes the very event the arm is
#     examining, and every one of these scans looks for a different kind of
#     event than the arm it sits in, so the extra element can never match.
#
#   objects.rs `< with >`: the boundary reads `modes.len() < 2` as `> 2`, and
#     the pool's one modal spell (Ghoulcaller's Chant) has exactly two modes.
#
#   stack.rs `== with !=`: the X-funding prompt's "was the sacrifice already
#     made?" block. Reaching it needs an activated ability with both an X in
#     its cost and a sacrifice cost, and the pool's three sacrifice-cost
#     abilities (Grimgrin, Skirsdag Cultist, Disciple of Griselbrand) have no
#     X. (An earlier version of this note also claimed the granted-flashback
#     lookup in the same function; that claim was wrong -- Past in Flames puts
#     several grants side by side and reading the wrong one invents an X.
#     `a_granted_flashback_cost_is_read_off_the_grant_that_names_the_spell`
#     now kills that mutant and the guard-to-`true` one beside it.)
#
#   stack.rs guard `*target == obj.id` forced to `false`: the surviving third
#     of that same site. It makes the granted-flashback lookup find nothing,
#     which differs from finding the right grant only when a GRANTED flashback
#     cost has an X. Devil's Play is the only card in the pool whose mana cost
#     has an X, and it prints its own flashback cost, which is consulted first
#     and short-circuits the lookup.
#
#   legal.rs `- with +` in `choose`: `k.min(n - k)` becomes `k.min(n + k)`,
#     i.e. plain `k` (the function returns 0 above when `k > n`). The `min` is
#     the C(n,k) = C(n,n-k) symmetry, taken only to run the shorter fold; the
#     binomial it computes is the same number either way.
#
#   legal.rs `< with <=` in `loyalty`: `def.loyalty_change < 0` becomes
#     `<= 0`, which lets a change of exactly 0 into the body -- where the test
#     is `0.unsigned_abs() > counters`, i.e. `0 > n`, false for every n.
#
#   transition.rs `+ with -` in `mana_demanded`: the mutated term is
#     `cost.colorless_amount()`, the {C} symbol. No card in the pool carries
#     one (`ManaSymbol::Colorless` appears nowhere under src/cards), so the
#     term is always 0 and `x + 0` is `x - 0`.
#
#   transition.rs `> with >=` in `action_contract`: `s > d` compares the
#     position of the `LibraryShuffled` event with the position of the first
#     `CardDrawn` in one and the same event vector. Two events of different
#     kinds cannot occupy the same index, so `s == d` is impossible and the
#     two comparisons agree everywhere.

#   transition.rs, the `Discarded` guard `*player == who` forced to true:
#     the window is one action's events, and the only action that discards

#     occurrences are inside the legend rule's `doomed`, whose damage,
#     deathtouch and toughness disjuncts only matter when the kept
#     permanent is off the battlefield with no `LeftBattlefield` event in
#     the window. `move_object` is the only way off the battlefield and
#     always emits one, so the event disjunct beside them is already true
#     whenever they are consulted. (The other two occurrences of this
#     normalized line, in the cast and activation contracts, were killed.)
#

#     in `refilled`, which asks whether a card came into the library after

#     disjuncts true (moving always bumps the zone-change count) and one
#     already in the library has both false; the states that would tell the
#     two apart -- arriving without a count bump, or a count bump while
#     staying in the library -- neither `move_object` nor
